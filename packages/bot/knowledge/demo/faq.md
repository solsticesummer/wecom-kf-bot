# 示例助手 常见问题

Fixture corpus for the `demo` tenant. Its only job is to be recognisably different from the
other tenant's FAQ, so a test can prove that a retrieval outage falls back to the right
tenant's knowledge. Deliberately mentions no other tenant by name — the isolation test
asserts exactly that. Real content would go here for a real tenant.

## 示例助手是什么

示例助手是一个用于演示多租户配置的示例产品，不是真实产品。

## 收费标准

示例助手不收费，因为它并不存在。
